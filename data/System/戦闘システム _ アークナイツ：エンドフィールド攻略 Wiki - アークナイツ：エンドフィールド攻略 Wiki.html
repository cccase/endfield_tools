基本システム †

プレイヤーは最大4人のキャラクター（オペレーター）でパーティーを編成。
リアルタイムで操作オペレーターの切り替えや、オペレーターのスキル（通常攻撃、戦技、連携技、必殺技）を発動しながら戦闘を行う。

  • 戦技を発動するための戦技ポイント（SP）はパーティーで共有
  • 各オペレーターは事前に設定したアイテム（主に回復アイテム）を1戦闘につき3回まで自動的に使用する

プレイヤーが操作していないオペレーターは自動的に行動し、回避や通常攻撃を行う。
また、任意のタイミングで戦技、連携技、必殺技を発動させることもできる。

基本戦闘チュートリアルは各オペレーターの最適な使用方法を解説してくれるため、積極的に活用しよう。

↑

スキル †

戦技、連携技、必殺技を合わせてスキルと呼ぶ。各スキルはスキルレベル1~9 + 特化1~3まで強化することができる。
通常攻撃はカテゴリ上スキル欄に配置されているが、素質やセット効果の発動条件としての「スキル」としては扱われない*1。

↑

通常攻撃（重攻撃、終撃、落下攻撃） †

基本となる攻撃手段。対応するボタン（キー）を長押しすると、自動で連続攻撃（コンボ）が発生する。

コンボの最終段は重攻撃が発生する。
操作中のオペレーターの重攻撃はSPを回復し、敵にブレイク値を与えることが可能。
特に近接武器は重攻撃の回転が早く、より多くのブレイク値を与えることができる場合が多い。

ブレイク値を一定以上ためると、敵はブレイク状態になる。
ブレイク状態の敵には自動的に大ダメージ＆SP回復する終撃に切り替わる。（１回のみ）

空中にいるときに通常攻撃をすると急降下して攻撃する落下攻撃が発生する。
なお、回避行動や落下攻撃をする際にコンボが途切れることはない。

↑

戦技 †

パーティー全体で共有するSPを消費して使用する。
他のゲームで言うところのスキルに相当するが、本作では前述のとおり「戦技/連携技/必殺技」の総称がスキルであるため注意。

SPは時間経過で回復するほか、操作中オペレーターの重攻撃*2、ジャスト回避、先鋒のスキルで回復することができる。
戦技使用時、SP回復は0.5秒間停止する。

方法SP回復
ジャスト回避3
終撃22.5
1秒8
12.5秒100

クールタイムが無いため、SPの許す限り連続で使用することができる。

SPの現在値は画面下部中央の3本のゲージで確認できる。黄色のゲージ1本でSP100。（PC版）

↑

連携技 †

特定の条件を満たすことで発動可能なスキル。
条件は各オペレーターごとに設定されている。（例：重攻撃を命中させる、ダメージを受ける、など）
条件を満たしてから発動可能な猶予は6秒間。

クールタイムがあり、長さは発動条件の満たしやすさや効果と比例する傾向がある。
同じタイミングで連携技が複数発動する場合、編成順が前のオペレーターから順に発動できる。（例：ペリカとアルデリアがいる場合に重攻撃など）

連携技のクールタイムは画面左下の白いゲージで確認できる。（PC版）

↑

必殺技 †

必殺チャージを消費して、大技を放つ。

必殺チャージは、戦技や連携技を使うことで増加する。
基本的に戦技では編成内の全員の必殺チャージが6.5増加し、連携技では発動したオペレーターのみ必殺チャージが10増加する。
アークライトの連携技のチャージ量が5であるように一部例外が存在する。

また、攻撃系のスキルは、敵に命中しないと必殺チャージが増加しない。

必殺チャージの状況は画面右下の必殺技アイコンで確認できる。（PC版）

↑

SP返還と必殺チャージの関係 †

ゲーム内の説明に「返還されたSPを消費しても必殺チャージは回復しない。」とあるように、SP返還の後に発動した戦技による必殺チャージ回復量は以下になる。

　返還SP消費時の必殺チャージ回復量 = ((100 - 今回消費した返還SP) / 100) * 6.5

この返還SPはSPゲージの先頭に置かれるので、消費の際には通常のSPよりも返還SPが優先される。
また、この変換SPはSPゲージが回復するにつれて右に押し出されていく。
これはSPゲージが溜まりきっても続けられ、時間経過によるSP回復でゲージからはみ出した返還SPは消滅しその分が通常SPに置き換わる。
なおSP回復が発生した場合の回復SPもSPゲージの先頭に置かれるが、これは演出上そうなっているだけで回復SPは返還SPの後ろに挿入される。
そのためSP返還 → SP回復 → 戦技とした場合はSP返還後に最初に発動したこの戦技の必殺チャージ量が減少する。
またSP回復で返還SPをゲージ外に押し出す事はできないようなので、SP回復を大量に発生させて返還SPを消し去る事は不可能である。

↑

必殺チャージの回復効率 †

+ 必殺チャージの回復効率（より詳細な話）

対象キャラの必殺チャージが0の状態から必殺技が使用可能になるまでの
パーティー全員の戦技の使用回数をNSC（Normal Skill Count）、
対象キャラの連携技の使用回数をCSC（Combo Skill Count）、
対象キャラの必殺チャージの回復効率をUSG（Ultimate SP Gain）とし、
対象キャラの必殺チャージ消費をUSC（Ultimate Skill Cost）とすると
特殊なキャラ以外は以下の式が成り立つ。
　(6.5 * NSC + 10 * CSC) * (1 + USG * 0.01) >= USC

使用回数
ここでは使用回数と書いているが、カウンター型の戦技だと使用するだけではチャージが少量しか回復せず反撃が発生した時に残りのチャージが回復するなど
使用するだけでは満額チャージされない仕様の技もあるため正確には使用回数だと上式は成立しない。
しかしチャージ量の上限を決めるのは使用回数である事も確かなので、ここでは使用回数で上式が成立するとして話を進める。

なおステータス画面では必殺チャージの回復効率にデフォルト値の100%が加算された値が表示されているが、
それだと装備などで上げなければならない値が分かりにくいので、あえて100%を足していない値で式を作っている。

この式から最低限必要な必殺チャージの回復効率（USG）を求めると以下の表になる。
必殺チャージの回復効率がこの表の値を超えた時に必殺技が使用可能になるまでの戦技や連携技の使用回数が減少する。
逆に書くと表の値の間の回復効率はゲーム上では全て同じ効果しかなく、表の値を超えない程度に回復効率を上げる行為は無意味である。
自分がローテーションで使う戦技や連携技の回数を計算して表の該当するセルの値を少し超えるくらいにするのがお勧めである。

ただし返還SPを消費した場合はそのSP分必殺チャージが回復しないので、パーティーにSP返還能力を持つメンバーがいるとこの表の回復効率では不足するので注意が必要になる。
もし正確な回復効率が知りたい場合は下記のUSG表出力プログラムを書き換えて各自のパーティーに合ったUSG表を出力してほしい。

なおゲームでは小数第1位に丸められて表示されているため、取り扱いには注意が必要になる。
最小USG表では安全のために小数第2位以下を切り上げているが、
表の値と装備品ひとつひとつの必殺チャージの回復効率を自分で足し合わせて計算した値を比較する場合は、表の値に+0.7して使用することを勧める。

ただし最小USG表の値とゲーム内で表示されている必殺チャージの回復効率の合計を比較する場合なら表の値に+0.1して使用する、
つまり回復効率の合計 > 最小USG表の値ならば問題ない。

回復効率の誤差について

NSCとCSCが与えられた時にUSCが対象キャラの必殺チャージ消費以上になる条件を考えると、
　回復効率 >= 最小USG
であれば条件を満たす。

また最小USG表の値は小数第2位以下を切り上げているので
　真の最小USG + 0.1 > 最小USG表の値 >= 真の最小USG
よって
　回復効率 >= 最小USG表の値 >= 真の最小USG
であれば必ずNSCとCSCから計算したUSCが対象キャラの必殺チャージ消費以上となる。

この条件を満たす回復効率を満足する装備を求めるためにゲーム内の装備品の必殺チャージの回復効率の値を使いたいが、
この数字は小数第1位までしか表示されておらず丸め方式も分からない。
しかし合理的に考えると
　真の回復効率 + 0.1 > ゲーム内で表示されている回復効率 > 真の回復効率 - 0.1
であり誤差は最大でも0.1より小さくなる。

また防具については加工で1.3倍まで強化されるので、加工後の回復効率を初期値から自分で計算した場合の誤差は
　0.1 * 1.3 = 0.13
より小さくなる。
なので武器と防具4つの誤差を足し合わせる時の誤差は
　0.1 + 0.13 * 4 = 0.62
より小さくなり、これが最大誤差となる。

最小USG表でもゲーム内でも小数第1位までしか表示しておらず、小数第2位以下の数字を計算する事は無いので0.62を0.7に切り上げると
　真の回復効率 + 0.7 > 自分で計算した回復効率 > 真の回復効率 - 0.7
　自分で計算した回復効率 + 0.7 > 真の回復効率 > 自分で計算した回復効率 - 0.7

ここで最小USG表では小数第2位以下を切り上げているから
　真の最小USG + 0.1 > 最小USG表の値 >= 真の最小USG

満たしたい条件は
　真の回復効率 >= 真の最小USG
で
　最小USG表の値 >= 真の最小USG
なのだから
　真の回復効率 >= 最小USG表の値
であれば必ず条件を満たす。
そして
　真の回復効率 > 自分で計算した回復効率 - 0.7
だから

キャラの能力に「必要な必殺チャージ-a%」のようなものがある場合はこの表の値をそのまま使用できないが、
その時の最低限必要な必殺チャージの回復効率（USG'）は以下の様に計算できる。
　USG' = USG * (1 - a * 0.01) - a

例えば「必要な必殺チャージ-15%」の能力適用後の最低限必要な必殺チャージの回復効率は以下で求められる。
　USG' = USG * (1 - 15 * 0.01) - 15
　USG' = USG * 0.85 - 15

USG'の式について

まず最低限必要な必殺チャージの回復効率（USG）を式にすると以下になる。
　(6.5 * NSC + 10 * CSC) * (1 + USG * 0.01) = USC
この式をUSGについて解く。

前提を
　(6.5 * NSC + 10 * CSC) = X > 0
とすると
　(1 + USG * 0.01) = USC / X
　USG * 0.01 = (USC / X) - 1
　USG = ( (USC / X) - 1 ) / 0.01

能力適用後の必殺チャージ消費をUSC'とすると以下になる。
　USC' = USC * (1 - a * 0.01)

またこの能力適用後の最低限必要な必殺チャージの回復効率USG'は以下になる。
　USG' = ( (USC' / X) - 1 ) / 0.01

　USC'についての式を代入すると
　USG' = ( ( USC * (1 - a * 0.01) / X ) - 1 ) / 0.01
　
USGの式から
　USG = ( (USC / X) - 1 ) / 0.01
　USG * 0.01 = (USC / X) - 1
　USG * 0.01 + 1 = USC / X

よって
　USG' = ( (USG * 0.01 + 1) * (1 - a * 0.01) - 1 ) / 0.01
　USG' = ( (USG * 0.01) * (1 - a * 0.01) + (1 - a * 0.01) - 1 ) / 0.01
　USG' = ( (USG * 0.01) * (1 - a * 0.01) - a * 0.01 ) / 0.01
　USG' = USG * (1 - a * 0.01) - a

ブレイク †

累積ブレイク値が最大になると敵が長時間行動不能な「ブレイク」状態になり被ダメージがアップする。

操作中のオペレータの重攻撃や特定のスキルでブレイク値を与えることができる。
与えるブレイク値は近接武器＞遠距離武器で設定される傾向にある。

ブレイク中の敵に通常攻撃を行うと致命の一撃「終撃」に変化し、大ダメージを与えSPを回復する。

ボス級の敵はブレイク値に複数の閾値が設定されており、閾値を超えるたびに怯みが発生する。格上相手や中盤以降の戦闘では特に重要。

浮遊または転倒を付与時にアーツ強度50％の値で乗算、および宏山点剣セットの物理異常を付与時にブレイク値10を加算する効果について、
物理異常スキルは2クラッシュ目以降から物理異常を付与され、上記ブレイク値が追加される。（1クラッシュ目はクラッシュ付与のみ）
※ただし強制的に物理異常を付与するスキルは、1クラッシュ目からブレイク値が追加される。（ギルベルタの連携技など）

ブレイク値は以下の計算で算出（推定）
(基礎ブレイク値＋宏山点剣セット効果)×ブレイク効率×(アーツ強度×0.5)　※アーツ強度の計算結果は小数点以下を切り捨て

アーツ（属性） †

ダメージの種類には物理ダメージ、アーツダメージ、超域ダメージがある。
アーツダメージはさらに灼熱ダメージ、電磁ダメージ、寒冷ダメージ、自然ダメージに分類される。
超域ダメージは敵専用。

付着状態はさらに付着を重ね掛けすることで各種「異常」や「爆発」へと発展する。

クラッシュ、物理異常（浮遊・転倒・猛撃・破砕） †

特定のスキルによって敵に物理異常を付与することができる。

1回目の物理異常を受けた敵は、物理異常の効果は直ちに発動せず、まず「クラッシュ状態」となる。
クラッシュ状態は20秒持続する。クラッシュ状態を重ね掛けすると持続時間は更新される。
敵がすでにクラッシュ状態の場合、物理異常の効果が発動する。

物理異常には「浮遊」「転倒」「猛撃」「破砕」がある。

  • 「浮遊」はクラッシュ段階が1増加（最大4段階）し、ブレイク値と物理ダメージを与え、敵が一定時間行動不能（浮遊）になる
  • 「転倒」はクラッシュ段階が1増加（最大4段階）し、ブレイク値と物理ダメージを与え、敵が一定時間行動不能（転倒）になる
  • 「猛撃」はクラッシュをすべて消費し、消費した段階に応じて高い物理ダメージを与える
  • 「破砕」はクラッシュをすべて消費し、消費した段階に応じて物理ダメージを与え、被物理ダメージを増加させるデバフを付与する

破砕のデバフ効果量は消費したクラッシュ数に応じて12%/16%/20%/24%、持続時間は12秒/18秒/24秒/30秒。

強制物理異常

一部のスキルは物理異常そのものを強制的に付与する。
対象がクラッシュ状態であるかどうかに関わらず「浮遊」「転倒」を付与することができる。
この方法で「浮遊」「転倒」を付与した場合もクラッシュを1段階増加させる。

アーツ付着（灼熱付着・電磁付着・寒冷付着・自然付着） †

特定のスキルによって敵にアーツ付着状態を付与することができる。
アーツ付着それ自体には効果はないが、後述の「アーツ異常」及び一部オペレーターのスキルや武器の効果と相互作用する。
同種のアーツ付着は4段階まで重ね掛けすることができる。
アーツ付着は20秒持続する。アーツ付着を重ね掛けすると持続時間は更新される。

アーツ爆発 †

アーツ付着状態の敵にさらに同じ属性のアーツ付着を重ねることでアーツ爆発が発生する。
アーツ爆発は対応する属性のアーツダメージを与える。
このダメージは付着段階に関わらず一定。
同じ属性の付着を重ねる事で効果を発揮するため、アーツ爆発を狙う場合は出来るだけ属性を統一するか、異なる属性の付着手段を使わないようにして運用する事が求められる。

アーツ異常（燃焼・感電・凍結・腐食、粉砕） †

アーツ付着状態の敵に異なる属性のアーツ付着を与えると、敵のアーツ付着段階を全て消費しアーツ異常状態にする。
下地のアーツ付着の属性に関係なく、後から被せた側のアーツ付着属性によって発生するアーツ異常が決定される。
発動条件の都合上、起こしたいアーツ異常と異なる属性のアーツ付着を用意する必要がある点に注意。

  • ＋灼熱付着で「燃焼」……灼熱ダメージを与え、さらに灼熱属性のスリップダメージを与える
  • ＋電磁付着で「感電」……電磁ダメージを与え、被アーツダメージアップ
  • ＋寒冷付着で「凍結」……寒冷ダメージを与え、小・中型エネミーを行動不能にする（大型エネミーにも付与自体は可能）
  • ＋自然付着で「腐食」……自然ダメージを与え、全属性耐性を少しずつ減少させる

アーツ異常状態には段階があり、発生時に消費した付着段階に応じて付与時のダメージ・異常効果量・異常持続時間などがそれぞれ強化される。

燃焼のスリップダメージは1秒間隔のDoTダメージで、付着段階によらず持続時間は10秒。消費した付着段階に応じて灼熱ダメージを与える。

感電の効果量は消費した付着数に応じて12%/16%/20%/24%、持続時間は12秒/18秒/24秒/30秒。

凍結の効果時間は付着段階に応じて変化する。（詳細要確認）
凍結状態の敵にさらにクラッシュを付与することで、凍結を解除しつつ粉砕が発生する。
粉砕は解除した凍結の段階に応じて物理ダメージを与える。粉砕ダメージはクラッシュを付与したオペレーターのステータスを参照する。

腐食は付着段階によらず持続時間は15秒で、10秒で効果が最大となる。効果量は最大12/16/20/24
腐食状態を腐食で上書きした場合、後からかけた腐食の付着段階に関わらず耐性低下値が維持される。耐性低下値が後からかけた腐食の上限値に到達していなかった場合、後からかけた腐食の上限値まで徐々に耐性低下量が増えていく。

強制アーツ異常

一部のスキルはアーツ異常そのものを強制的に付与する。（例：アルデリア 連携技）
この方法で付与されたアーツ異常状態は付与時のダメージが発生しない。

付着を消費せず直接付与されたアーツ異常は、特記のない限り1段階相当の効果で持続時間は該当スキルによって決まる。

戦闘のコツ †

編成

  • 個々のオペレーターの強さよりも、オペレーター間の（戦技や連携の）シナジーが最重要な戦闘デザイン
    各オペレーターのスキルや装備効果を組み合わせて、物理異常やアーツ異常/爆発、バフやデバフを駆使して効果的に戦闘できるように編成を工夫する。
    ★6だけで固めるよりも、オペレーター間の相性が良い★5や★4を交えて編成したほうが強い編成になりやすい。
    また、バフやデバフの種類を散らした方が火力が伸びやすい。
  • 先鋒を編成する
    先鋒は戦技の発動に必要なSPを効率的に稼ぐ能力を持つ。
    戦技の発動頻度が高まることで、必殺技の回転率向上やアーツ付着の頻度を高める効果が期待できる。

育成

  • 攻撃力不足を感じたらオペレーターの育成、武器のレベルや防具を見直そう
    • オペレーターのスキルやレベル
      • 潜在強化（凸）しても性能の変化は小さいことが多い
    • 武器のレベル
    • 防具
      • 特に能力値の高い胴防具や腕防具はメイン能力とサブ能力が一致したものを選択しよう。
  • 敵の攻撃が強いと感じたら防具を見直そう
    防具自体の防御力以外にも、能力値を高めると、耐久力を上げることができる。

プレイング

  • 敵のスキル中断用にSPを温存する
    相手の攻撃が苛烈で耐えられない時は、SPを温存する立ち回りを試してみよう。
    敵のスキルを中断する際は発生の早い戦技がおすすめ。
  • 遠距離オペレーターを操作すると安定しやすい
    通常攻撃が近距離型のオペレーターと比較して、遠距離型のオペレーターの方が敵との距離が離れるため攻撃を回避しやすい。
    与えるブレイク値の量などは近接武器＞遠距離武器の傾向にあるため、状況に応じて使い分けるのもいいだろう。

その他

  • アーツダメージとアーツ付着は異なることに注意。（例：物理ダメージ＆電磁付着付与、灼熱ダメージのみ（アーツ付着なし）など）
  • よくある、属性の間の相性（例：火は水に弱い等）はない
  • 「物理属性が不遇」、「主人公が弱い」といったことはない

ルール違反投稿について †

以下は荒れる原因となるので投稿自体を禁止とさせていただきます。

  • キャラに対する誹謗中傷・蔑称
    • キャラに対して性能・見た目・キャラ設定等に関し、無根拠に批判する場合はキャラに対する誹謗中傷に当たります。キャラの性能を評価する発言(強い、弱い等)は許容しておりますが、言葉遣いに注意してください。例えば、「○○のスキルが弱くて使う価値なし、雑魚」といった発言は、性能評価とキャラの誹謗中傷を同時に行っており、ルール違反対象となります。他にも「ゴミ、産廃、ブス、ハズレ、使えない」といった類の暴言ワードも違反対象になります。また、「貧乳」といったワードは書き方によって暴言になったり、好意的な文になったりしますので、注意しましょう。
  • 性行為を連想させる発言、過激なアダルトワード
    • 当サイトは年齢制限なしに閲覧できますので、性行為を連想させる発言、過激なアダルトワード(伏せ字含む)を禁止します。
    • ソフトなアダルトワードは許容しております。(例:えっちな、色っぽい、エロい、ムチムチ等)
  • 他者への誹謗中傷・喧嘩腰な書き込み
    • 他者とは、当wiki利用者様、公式運営、絵師、声優、現実に存在する個人、AI、ツイッター民といったグループも含まれます。
    • 運営に対する投稿について、「ここを改善してくれたらいいのに」、「不具合を早く直して欲しい」、「メンテ長すぎるよ」といった、ユーザーの意見ととれる書き込みは許容しておりますが、汚い言葉を使って貶める行為は許容しておりません。

    • 喧嘩腰な書き込みとは、「～しろよ、～やれよ。等の強い命令口調」「汚い言葉を使う」「見下す態度をとる」「挑発する」を指します。

  • 他サイト、アプリの宣伝・誹謗中傷 (ただし、攻略情報提供を目的としたyoutube動画や、当wikiにページ化されている攻略以外の情報(BGM、イラスト、絵師、関連商品のフィギュア、画集といった公式運営に関わりのある情報)のURL掲載、攻略サイトURLの掲載は認めます。)

愚痴は違反対象にならないの？ †

基本的に愚痴そのものを違反対象とはしていません。Wiki管理人は、愚痴もゲームにおけるユーザーのいち意見ととらえています。
