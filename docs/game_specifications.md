# アークナイツ：エンドフィールド ゲーム仕様調査書

本ドキュメントは、『アークナイツ：エンドフィールド』におけるキャラクターのステータス計算、スキルダメージ計算、バフ・デバフの重複仕様、およびシミュレーション用の敵（案山子）の仕様をまとめたものである。

---

## 1. ステータス算出仕様

### 1.1 基礎能力値（四維ステータス）
各オペレーターは以下の4つの基本ステータスを持つ。

* **筋力 (Strength / STR)**: 主に最大HPや物理防御等に影響。
* **敏捷 (Agility / AGI)**: 主に物理耐性や攻撃速度等に影響。
* **知性 (Intellect / INT)**: 主にアーツ耐性（術耐性）や状態異常強度等に影響。
* **意志 (Willpower / WIL)**: 主に被回復量やダウン抵抗等に影響。

#### メイン能力・サブ能力（能力値付加）
各キャラクターには得意ステータスとして**メイン能力**（1つ）と**サブ能力**（1つ）が設定されている。
これらの数値に応じて、攻撃力に乗算される「能力値倍率（能力値付加）」が算出される。

* **メイン能力値**: 1ptにつき **+0.5%** （0.005）
* **サブ能力値**: 1ptにつき **+0.2%** （0.002）

$$\text{能力値倍率} = 1 + (\text{メイン能力値} \times 0.005) + (\text{サブ能力値} \times 0.002)$$

### 1.2 攻撃力 (ATK) の算出式
キャラクターの最終的な攻撃力は、基礎攻撃力に装備やスキルのバフを反映し、能力値倍率を乗算して算出される。

$$\text{最終攻撃力} = \left[ (\text{基礎攻撃力}_{\text{キャラ}} + \text{基礎攻撃力}_{\text{武器}}) \times (1 + \sum \text{攻撃力}\% \text{バフ}) + \sum \text{攻撃力固定値バフ} \right] \times \text{能力値倍率}$$

* **基礎攻撃力**: キャラクター固有の基礎攻撃力（Lv.MAX）と、装備中の武器の基礎攻撃力（Lv.MAX）の合算値（いわゆる白値）。
* **攻撃力%バフ**: 武器スキル、防具のメイン/サブステータス、防具セット効果、バフスキルなどによる「攻撃力+X%」の合算値（同枠加算）。
* **攻撃力固定値バフ**: 防具のフラット値や一部支援スキルによる「攻撃力+X」の合算値。

### 1.3 会心ステータス
* **会心率 (Crit Rate)**: デフォルト基礎値 5.0% (0.05)。
* **会心ダメージ (Crit Damage)**: デフォルト基礎値 50.0% (0.50)。
  * クリティカル発生時のダメージ倍率は $1 + \text{会心ダメージ} = 1.50$ (150%)。
  * 期待値計算を行う場合は $1 + (\text{会心率} \times \text{会心ダメージ})$ を乗算。

### 1.4 アーツ強度 (Arts Intensity)
* 主にアーツダメージ、アーツ異常（燃焼、感電、凍結、腐食など）の発生時ダメージや付加効果に寄与する。

## 2. ダメージ計算式

エンドフィールドのダメージ計算は、減算ではなく各乗算区を掛け合わせる多乗区（マルチプライヤー）方式を採用している。同一条件下において乱数は存在せず、確定したダメージが出力される。

### 2.1 総合計算式
$$\begin{aligned}
\text{最終ダメージ} = & \text{最終攻撃力} \\
& \times \text{スキル倍率} \\
& \times \text{会心係数} \\
& \times (1 + \text{属性ダメージUP} + \text{スキルダメージUP} + \text{全ダメージUP}) \\
& \times \text{防御補正} \\
& \times \text{耐性補正} \\
& \times (1 + \text{被ダメージUP / 脆弱}) \\
& \times \text{ブレイク補正} \\
& \times \text{独立乗算補正（リンク補正、特定武器増幅など）}
\end{aligned}$$

### 2.2 各乗算区の詳細

1. **スキル倍率 (Skill Multiplier)**
   * 発動するスキル（戦技・連携技・必殺技）のレベル（Lv.9〜特化3）に応じた倍率。
   * 多段ヒットの場合は、全段合計倍率または各ヒットごとの倍率×段数として計算。

2. **会心係数 (Critical Multiplier)**
   * **期待値**: $1 + (\text{会心率} \times \text{会心ダメージ})$
   * **会心発生時**: $1 + \text{会心ダメージ}$
   * **非会心時**: $1.0$

3. **ダメージ加算区（与ダメージUP）**
   * 「物理ダメージUP」「灼熱ダメージUP」「戦技ダメージUP」「必殺技ダメージUP」「与ダメージUP」などは同枠として加算される。
   * 例: 物理ダメージ+20%、戦技ダメージ+15%の場合、$(1 + 0.20 + 0.15) = 1.35$

4. **防御補正 (Defense Multiplier)**
   * 防御力は除算モデルを採用。
   $$\text{防御補正} = \frac{100}{100 + \text{敵防御力}}$$
   * ※敵防御力が100の場合、補正は $100 / 200 = 0.5$（ダメージ50%カット）。
   * 破防・防御無視効果がある場合、敵防御力から相殺して計算する。

5. **耐性補正 (Resistance Multiplier)**
   * 敵の属性耐性（物理耐性、灼熱耐性など）による軽減。
   $$\text{耐性補正} = 1 - \frac{\text{属性耐性}(\%)}{100}$$
   * 耐性ダウンデバフによって耐性がマイナスになった場合、耐性補正は1.0を超えダメージが増加する。

6. **被ダメージUP / 脆弱区 (Vulnerability / Damage Taken)**
   * 敵に付与された「受けるダメージ+X%」「脆弱+X%」などのデバフ枠。
   $$\text{被ダメージ補正} = 1 + \sum \text{被ダメージUP / 脆弱}$$

7. **ブレイク補正 (Break / Stun Multiplier)**
   * 敵のブレイクゲージ（クラッシュ）を削り切りダウンさせた「ブレイク（失衡）」状態のダメージ倍率。
   * 通常時: $1.0$
   * ブレイク時: デフォルト $1.5$ 〜 $2.0$（案山子設定や特定キャラのスキルで変動可能）。

8. **独立乗算補正**
   * タクティカルリンク状態によるリンク補正や、武器効果などの「独立して乗算される」特記効果。

## 3. バフ・デバフの重複仕様

1. **同枠ステータス加算**:
   * 同系統の加算効果（例: 攻撃力+X%, 物理ダメージ+X%）は各乗算区の中で単純加算される。
2. **同名効果の重ね掛け可否**:
   * **「同名効果は重ね掛け不可」**:
     * 同一の武器パッシブや防具効果から複数回トリガーされた場合、効果量はスタックせず、持続時間のみ更新される（リフレッシュ）。
   * **「同名効果は◯回まで重ね掛け可能」「持続時間は個別にカウント」**:
     * 設定された最大スタック数（maxStacks）まで効果が加算重複し、各スタックの残り持続時間は独立して減衰する。
3. **異なる発生源の重複**:
   * キャラクターAの戦技バフ、キャラクターBの天賦バフ、武器パッシブ、防具セット効果は、効果の種類が同一であっても原則としてすべて重複（スタック）して計算される。

## 4. 案山子（ターゲット）の仕様

本ツールの計算対象となる敵「案山子（ダミー）」のパラメータ仕様。ユーザーが自由に数値を調整可能とする。

| パラメータ | 内部キー | デフォルト値 | 説明 |
| :--- | :--- | :--- | :--- |
| 敵レベル | `level` | `90` | 案山子のレベル（Lv.MAX固定基準） |
| 防御力 | `defense` | `100` | 敵の物理・アーツ共通の基礎防御力 |
| 物理耐性 | `physicalRes` | `0` (%) | 物理ダメージに対する軽減率 |
| 灼熱耐性 | `heatRes` | `0` (%) | 灼熱属性に対する軽減率 |
| 電磁耐性 | `electricRes` | `0` (%) | 電磁属性に対する軽減率 |
| 寒冷耐性 | `cryoRes` | `0` (%) | 寒冷属性に対する軽減率 |
| 自然耐性 | `natureRes` | `0` (%) | 自然属性に対する軽減率 |
| 被ダメージ補正 | `vulnerability` | `0` (%) | 敵が受けるダメージ増加デバフ |
| ブレイク状態 | `isBroken` | `false` | ブレイク中かどうかのフラグ |

| アーツ異常状態 | `artsAnomaly` | `none` | 元素反応による異常（none / combustion[燃焼] / corrosion[腐食] / freeze[凍結] / shock[感電]） |

## 5. アーツ付着・アーツ反応およびクラッシュ（衝撃・破砕）仕様

戦闘においてダメージを最大化するための2大基幹システム「アーツ付着・反応（元素系）」と「物理クラッシュ・破砕（物理系）」の仕様。

### 5.1 アーツ付着（Arts Infliction）とアーツ爆発（Arts Burst）
1. **アーツ付着**:
   * **どのスキルを使用しても、1回の付与につき「1段階」までしか付着しない。**
   * 灼熱、寒冷、電磁、自然のいずれかのアーツスキルを命中させると、敵に対象属性の「アーツ付着」が1段階付与される。
2. **スタックとアーツ爆発 (Arts Burst)**:
   * 同じ属性（寒冷など）の付着は最大 **「4段階」** までスタック可能。
   * **4段階（最大）に達した時点で「アーツ爆発」が発生**し、追加のアーツ属性ダメージを与える。
   * *装備連動例*: 天険セット（自然爆発・寒冷爆発時に20秒間アーツ強度+16、最大3段スタック）。

### 5.2 アーツ異常（Arts Anomaly）と初期付着段階スケール
1. **アーツ異常の発生条件**:
   * すでに属性が付着している状態（1〜4段階）に対して**「異なる属性」**を付着させた場合、**後から付着した属性に応じた「アーツ異常」**が発生する（初期付着は消費される）。
2. **異常のダメージ/効果スケール**:
   * アーツ異常の効果量は**「初めに付着していた属性が何であったか」には一切依存せず、「初めに付着していた属性の段階数（スタック数：1〜4段階）」にのみ依存**して効果・ダメージがスケールする。

| アーツ異常名 | トリガー条件（後から付着した属性） | 効果・ダメージ特性（初期付着段階数1〜4でスケール） | 装備・スキルシナジー |
| :--- | :--- | :--- | :--- |
| **燃焼 (Combustion)** | 任意の属性付着中 → **灼熱**付着 | 灼熱大ダメージ ＋ 継続ダメージ(DoT) | **火山用セット**: 敵を燃焼状態にすると10秒間灼熱ダメージ+50% |
| **腐食 (Corrosion)** | 任意の属性付着中 → **自然**付着 | 自然大ダメージ ＋ 敵の全属性耐性ダウン | **火山用セット**: 敵を腐食状態にすると10秒間自然ダメージ+50% |
| **凝固/凍結 (Freeze)** | 任意の属性付着中 → **寒冷**付着 | 寒冷大ダメージ ＋ 敵の行動停止(凍結) | 物理追撃による「砕氷」のトリガー |
| **感電 (Electrification)** | 任意の属性付着中 → **電磁**付着 | 電磁大ダメージ ＋ アーツ被ダメージ増加 | アーツ脆弱付与による全体DPS加速 |

### 5.3 物理クラッシュ（Crush）の付与・消費仕様
クラッシュには**「付与するタイプ（浮遊・転倒など）」**と**「消費するタイプ（猛撃・破砕）」**の2種類が存在し、最大4段階まで蓄積される。

1. **現在の段階数が「0段階」のとき**:
   * **「付与するタイプ」と「消費するタイプ」のどちらを使用しても、「1段階」になる**（0段階の時に消費タイプを使っても消費は発生せず、1段階の付与として機能する）。
2. **現在の段階数が「1段階以上」のとき**:
   * **「付与するタイプ (`inflict`)」**を使うと、段階数が `+1` 増加する（最大4段階）。
   * **「消費するタイプ (`consume_smash` / `consume_shatter`)」**を使うと、現在の段階数（1〜4段階）をすべて消費（0段階へリセット）し、**消費した段階数に応じた追加効果（ダメージボーナス等）**が得られる。
   * *装備連動例*: **旧鋒セット**
     * 装備中攻撃力+8%。
     * 自身が敵に猛撃・破砕を与える時、消費する最大のクラッシュ段階数に応じて、20秒間自身の物理ダメージ+[6% × 消費した段階数]（最大4段階消費で物理ダメージ+24%）。
     * 目標が物理脆弱・ブレイク状態の場合、上記ボーナスが1.5倍（**最大物理ダメージ+36%**）。
3. **砕氷 (Shatter)**:
   * 寒冷異常によって凍結/凝固した敵に対し、物理のクラッシュスキルを命中させると「砕氷」が発生（凍結時の初期段階数に応じてスケール）。

### 5.4 ダメージ計算ロジックへの反映ルール
シミュレーションツールにおける計算時は以下の優先順位で適用する：
1. **付着・異常による耐性/脆弱補正**:
   * 敵が「腐食状態」の場合、初期付着段階数に応じて属性耐性を引き下げる。
   * 敵が「感電状態」の場合、初期付着段階数に応じてアーツ脆弱（被アーツダメージUP）を加算。
2. **装備の状況トリガー（火山セット・旧鋒セット等）**:
   * 敵の状態（燃焼/腐食、クラッシュ消費段階数、物理脆弱/ブレイク）に応じて、対応する属性ダメージUP・物理ダメージUPの補正値を自動で合算する。
3. **アーツ爆発・アーツ異常・砕氷の追加ダメージ**:
   * 4段階到達時のアーツ爆発、異属性付与時のアーツ異常（初期付着1〜4段階スケール）、凍結への物理追撃による砕氷ボーナスを加算。

### 5.5 スキルごとの付着・クラッシュ属性仕様とキャラクター固有仕様
1. **アーツ付着スキル**:
   * どのスキル（戦技・連携技・必殺技）を使用しても、1回の付与につき「1段階」付着する。
2. **物理クラッシュスキル**:
   * **クラッシュ付与タイプ (`inflict`)**: 浮遊・転倒など。0段階時は1段階にし、1段階以上時は段階数を+1する（最大4段）。
   * **クラッシュ消費タイプ (`consume_smash` / `consume_shatter`)**: 猛撃・破砕。0段階時は1段階にし、1段階以上時は全段階を消費して段階数に応じた追加効果を発動する。
3. **チェン（チェン・センユー）の固有仕様**:
   * **「チェン」が扱う状態異常は「浮遊（クラッシュ付与タイプ `inflict`）」のみである。「猛撃」や「破砕」（消費タイプ）は一切扱えない。**

### 5.6 特殊オペレーターの固有付着・形態仕様
1. **スー（Su）: 【墨筆の彩り / 1枠目属性模倣】**
   * **仕様**: 編成の1枠目（先頭キャラクター / 01位置）に配置されたオペレーターのアーツ属性を模倣し、自身の戦技（戦技1「山河を映して」、戦技2「墨継」）のアーツ付着属性をその属性（1段階）に変化させる。
2. **オクギ（Okugi）: 【知意双形態（ステータス分岐サポーター）】**
   * **仕様**: 最終ステータス（基礎値＋武器＋防具）における「知性」と「意志」の優劣によって、スキルの特性と付着挙動が2つの形態に分岐する（いずれの形態も1回の付与につき1段階）。
   * **知形態（知性 > 意志）**: 自然アーツ付着（1段階）を行い、敵に「自然脆弱デバフ（被ダメージ+15%）」を付与。
   * **意形態（意志 ≧ 知性）**: 敵に既存のアーツ付着が存在する場合はその属性の付着を+1段階進行させ、存在しない場合は自然アーツ付着（1段階）を付与する。
