# エージェントへの基本指示（ルール）

1. **言語設定**: 返信、思考プロセス、コミットメッセージはすべて日本語で行うこと。
2. **フェーズ単位の自律進行と確認**: 
    * 事前に `docs/design.md` を読み込み、そこに定義された「フェーズ」単位で作業を自律的に進めること。
    * フェーズ内の細かな仕様や実装手法が未定義だった場合は、作業を止めずに自己判断で最適なものを選定して進めてよい。
    * 1つのフェーズの実装とローカルでの動作確認が完了した時点で処理を一時停止し、事後報告（選定理由含む）と動作確認の依頼を行うこと。
3. **エラー発生時の作業分割（段階的フォールバック）**: 
    * 壊れた状態で進み続けないための必須ルールとする。
    * フェーズの進行中にエラーが発生し、自己解決が難航した場合は、そのフェーズの作業をより小さな単位（機能ごとなど）に分割し、分割した単位でユーザーに確認を求めること。
    * 分割後の作業でもさらにエラーが解決しない場合は、作業をさらに細分化し、ステップごとに状況を報告して指示を仰ぐこと。
4. **Git操作**: 指定のリポジトリ（https://github.com/cccase/endfield_tools.git）を使用する。フェーズ（または分割された作業単位）のユーザー承認が得られたタイミングで、コミット、プッシュを実行すること。
