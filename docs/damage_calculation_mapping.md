# ダメージ計算パラメータ名・計算グループ対応定義書

本ドキュメントは、『アークナイツ：エンドフィールド』のダメージ計算式（[Wikiru ダメージ計算式](https://arknights-endfield.wikiru.jp/?%E3%83%80%E3%83%A1%E3%83%BC%E3%82%B8%E8%A8%88%E7%AE%97%E5%BC%8F) 準拠）に基づき、各データ項目の呼び名（**パラメータ名**）と、計算式上どの加算・乗算枠に属するか（**計算グループ**）の紐づけを定義した公式仕様書です。

---

## 1. 用語の定義

* **パラメータ名**：ゲーム内のデータ項目（防具、武器、キャラクター、タイムラインバフ、敵など）の純粋な呼び方・スロット名。
* **計算グループ**：ダメージ計算式において、そのパラメータがどの計算枠（同枠加算・別枠乗算・減衰など）に属するかを示す分類名。

---

## 2. ダメージ基本計算式と計算グループ

オペレーターが敵に与えるダメージは、次式により一意に決定されます。

$$\begin{aligned}
\text{ダメージ} = &\ \text{参照スケール（攻撃力）} \\
&\times \text{ダメージ倍率補正} \\
&\times \text{ダメージUP補正} \\
&\times \text{増幅補正} \\
&\times \text{会心補正} \\
&\times \text{ブレイク補正} \\
&\times \text{防御補正} \\
&\times \text{耐性補正} \\
&\times \text{被ダメージ補正} \\
&\times \text{脆弱補正}
\end{aligned}$$

### 計算グループ一覧（全10枠）

| 計算グループ名 | 計算上の扱い | 同枠加算（グループ内で合算）される要素 |
| :--- | :--- | :--- |
| **① 参照スケール（攻撃力）** | 基準値 | **基礎攻撃力**（キャラ＋武器）<br>＋ **$\Sigma$攻撃力%**（防具、武器、素質、潜在、**戦闘中バフ**）<br>＋ **固定値付加**（料理バフ等）<br>× **能力値付加**（メイン能力$\times 0.5\%$ ＋ サブ能力$\times 0.2\%$） |
| **② ダメージ倍率補正** | 乗算 | 各スキルのモーション倍率%（戦技・連携・必殺のLv倍率） |
| **③ ダメージUP補正** | **加算 ($1 + \Sigma$)** | **【すべて同枠で合算】**<br>・属性ダメージUP（物理/灼熱/寒冷/電磁/自然）<br>・攻撃種別ダメージUP（戦技/連携/必殺/通常/全スキル）<br>・状況依存ダメージUP（燃焼時ダメUP、クラッシュ消費時の猛撃等）<br>・戦闘中のダメージUPバフ（全体/単体） |
| **④ 増幅補正** | **加算 ($1 + \Sigma$)** | **【同属性・アーツ増幅同士で合算】**<br>・属性増幅（灼熱/寒冷/電磁/自然増幅）<br>・アーツ増幅（ザイヒ戦技、生物補助4セット効果など） |
| **⑤ 被ダメージ補正** | **加算 ($1 + \Sigma$)** | **【敵デバフ同枠加算】**<br>・敵の受けるダメージ+X%（武器スキル3、素質、デバフ）<br>・**破砕**による物理被ダメージUP（クラッシュ消費）<br>・**感電**によるアーツ被ダメージUP（電磁異常） |
| **⑥ 脆弱補正** | **加算 ($1 + \Sigma$)** | **【脆弱同士で合算】**<br>・物理脆弱、アーツ脆弱（特定スキルによる脆弱デバフ） |
| **⑦ 耐性補正** | 減衰乗算 | 敵の基礎耐性値 － **耐性ダウン**（腐食による全耐性ダウン等） － 耐性無視 |
| **⑧ 防御補正** | 減衰乗算 | 敵防御力による減衰（一般に0.5、または $\frac{100}{100 + \text{敵防御力}}$） |
| **⑨ 会心補正** | 期待値/発生 | 会心率（基礎5%＋装備・バフの$\Sigma$会心率加算）$\times$ 会心ダメージ（基礎50%） |
| **⑩ ブレイク補正** | 乗算 | ブレイク状態時 1.3（非ブレイク時 1.0） |

## 4. 計算上の重要規則まとめ

1. **攻撃力バフの合流ルール**:
   * 装備の「攻撃力+X%」、素質・潜在の「攻撃力+X%」、タイムライン上の「全体/単体攻撃力バフ」はすべて **「① 参照スケール」の $\Sigma$攻撃力%** に同枠加算されます。
2. **ダメージUP補正の同枠加算ルール**:
   * 「物理ダメージUP」「属性ダメージUP」「戦技ダメージUP」「全スキルダメージUP」「戦闘中の与ダメージUPバフ」は別枠乗算ではなく、すべて **「③ ダメージUP補正」の中でそのまま合算 ($1 + \Sigma$)** されます。
3. **増幅補正の独立性・重ね掛けルール**:
   * 「増幅」はダメージUP補正とは独立した別枠乗算ですが、増幅同士（アーツ増幅＋属性増幅等）は **「④ 増幅補正」の中で加算 ($1 + \Sigma$)** されます。
4. **状態異常の帰属**:
   * **破砕**（物理被ダメUP）と**感電**（アーツ被ダメUP）は、武器やスキルの被ダメUPと同じ **「⑤ 被ダメージ補正」** に合算されます。
   * **腐食**（全耐性ダウン）は **「⑦ 耐性補正」** の敵耐性値から減算されます。
