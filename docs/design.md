# 開発設計書：アークナイツ：エンドフィールド ダメージ計算＆タイムラインツール

## 1. プロジェクト概要
本プロジェクトは、キャラクターのスキルダメージ計算、および動画編集ソフトのようなタイムラインUIを用いたバフ・デバフの可視化・手動調整が可能なシミュレーションツールの開発を目的とする。

## 2. 前提条件と対象スコープ
*   **対象攻撃**: 現段階ではスキルのダメージのみを計算対象とする（通常攻撃の計算は一旦妥協して見送った状態であり、将来的な拡張の余地を残す）。
*   **キャラクター条件**: キャラクターレベルはMAX固定。スキルレベルは「レベル9〜特化3」の範囲で設定可能とする。
*   **敵（ターゲット）条件**: 敵は固定の「案山子（ダミー）」とし、防御力や耐性などのステータス値を後からユーザーが自由に変更できる仕様とする。
*   **バフ・デバフの仕様**: 基本的に重複（スタック）ありとして計算する。ただし、ゲーム内テキストに「重複不可」等の記載がある一部の例外についてはフラグ管理等で対応する。

## 3. ディレクトリ・データ構造
データは機能および部位ごとに分割し、JSON形式で管理する。（※開発時は分割管理し、ビルド時にスクリプトで結合するハイブリッド方式を採用）

*   `Data/`
    *   `characters/` （キャラクターごとのJSON）
    *   `weapons/` （武器データのJSON）
    *   `armors/` （防具データのルート）
        *   `body/` （胴防具のJSON）
        *   `arms/` （腕防具のJSON）
        *   `accessories/` （アクセサリのJSON）

## 4. 開発フェーズ定義

### フェーズ1：ゲーム仕様の調査とデータスキーマ設計
1.  ウェブ検索等を用い、ステータス算出ルール（武器・防具の加算・乗算等）、ダメージ計算式、バフ・デバフの重複ルールを調査し、ドキュメントとして整理する。
2.  上記ディレクトリ構造に従い、敵（案山子）、キャラクター、各種装備のJSONスキーマ（データ構造）を設計する。

### フェーズ2：データ基盤の構築
1.  フェーズ1のスキーマに基づき、実際のキャラクターデータ、装備データ、スキル倍率のデータを収集し、JSONファイルとして作成する。
2.  分割されたJSONデータを結合し、アプリ側で読み込めるようにする（※結合用Node.jsスクリプトは既に提供済みのため組み込みのみ）。

### フェーズ3：ダメージ計算ロジックの実装
1.  フェーズ1で調査した計算式を用い、キャラクターの基礎ステータスに装備データの補正を加算・乗算するステータス算出ロジックを実装する。
2.  案山子のステータスと、バフ・デバフの状態を考慮した最終的なスキルダメージ計算ロジックを実装する。

### フェーズ4：タイムラインUIの実装
1.  バフ・デバフの発生と持続時間を視覚的に管理する、動画編集ソフトのタイムラインのようなUIを実装する。
2.  スキル発動に連動し、デフォルトで適切な時間軸（フレームまたは秒数）にバフ・デバフのブロックを自動配置する。
3.  配置されたバフ・デバフのブロックを、タイムライン上で手動でドラッグ等により移動・配置変更できる機能を実装する。

## 5. 【意思決定事項】タイムラインUIの実装方式について
フェーズ4のタイムラインUIの実装について、以下の2つの手法が考えられます。エージェントに指示を出す前に、どちらの方針を採用するか決定してください。

**案A：HTML/CSS（DOM操作）ベースでの実装**
*   **メリット**: 実装が比較的容易。各バフ・デバフのブロックをHTML要素（`<div>`等）として扱うため、ドラッグ＆ドロップライブラリ（SortableJSなど）やCSSによるスタイリングとの親和性が高い。
*   **デメリット**: タイムライン上に配置する要素が極端に多くなった場合、描画パフォーマンスが低下する可能性がある。
*   **推奨環境**: 一般的なWebブラウザ環境。要素数が数百程度までの想定。

**案B：Canvas API（WebGL）ベースでの実装**
*   **メリット**: 大量の要素を描画してもパフォーマンスが落ちにくく、スクロールや拡大縮小（ズーム）などの高度な描画処理をスムーズに行える。
*   **デメリット**: ドラッグ＆ドロップや当たり判定のロジックを自前で計算・実装する必要があるため、開発難易度が高く時間がかかる。
*   **推奨環境**: 高パフォーマンスが要求される本格的なプロ向けツールとしての動作を想定する場合。
