# アークナイツ：エンドフィールド 戦闘シミュレーター
(Arknights: Endfield Combat Simulator)

アークナイツ：エンドフィールドの「戦闘スキル回し（ローテーション）」と「必殺技ゲージ蓄積（SP/EP計算）」を可視化・シミュレーションするための非公式Webツールです。

## 概要

このツールは、キャラクターのスキル構成、凸数（潜在能力）、チーム編成を考慮し、タイムライン上にスキルを配置して必殺技のゲージ（EP）がどのように溜まるかを可視化します。各キャラクターの最低必要チャージ効率を逆算する機能も備えています。

**※ 本ツールは個人用の非公式ツールです。公式（Hypergryph / Gryphline）とは一切関係ありません。**
**※ 仕様変更などにより、実際のゲーム内の挙動と異なる場合があります。**

## 主な機能
- **キャラクター・スキル選択**: 編成したキャラクターの戦技・連携技・必殺技などのスキルをドラッグ＆ドロップで配置できます。
- **タイムライン可視化**: サイクル（フェーズ）ごとにスキルを管理・可視化できます。
- **SP・EP計算シミュレーション**: 消費SP、返還SP、連携技によるEP回復などを自動計算し、必殺技発動までの推移を可視化します。
- **URL共有**: 現在の編成とタイムラインの状態をURLとして出力し、他の環境に共有・保存できます。
- **画像出力**: 作成したタイムラインを画像として保存できます。

## 動作環境
ビルドツール（WebpackやVite等）は使用しておらず、純粋な HTML / CSS / Vanilla JavaScript で構築されています。
GitHub Pages などでそのままホスティングして利用することができます。ローカル環境で実行する場合は、CORSの制限を回避するためにローカルサーバー（VSCodeのLive Serverなど）経由で開くことを推奨します。
