# V4 Changes Implementation Details

今回のアップデート（V4）にて実装した変更内容は以下の通りです。

## 1. タイムライン機能の拡張・分割（マルチサイクル）
- タイムラインを1本の配列ではなく、複数に分割できる2次元配列（`timelineCycles`）へとリファクタリングしました。
- 各サイクル（枠）ごとに「複製」「削除」ボタンを設置し、タイムライン下部には「＋ サイクルを追加」ボタンを追加しました。これにより、1サイクルのローテーションを視覚的に分かりやすく管理・複製できるようになりました。
- ドラッグ＆ドロップ機能もこれに対応し、サイクル間でのスキルの移動が可能です。

## 2. 待機（仕切り）ブロックの追加
- スキルパレットに新しく「待機 (仕切り)」を追加しました。
- タイムライン上に配置すると、文字が表示されない細い縦線のブロック（`.bg-separator`）としてレンダリングされ、待ち時間などの隙間を表現できます。

## 3. エクスポート機能の刷新（URL生成・画像保存）
- 古いJSONファイルでの保存を廃止し、2種類の新しいエクスポート機能を追加しました。
  - **画像で保存**: `html2canvas` ライブラリを導入し、「画像として保存」ボタンを押すことで、現在のUI全体をpng画像としてダウンロードできます。
  - **URLをコピー**: 現在の編成、凸状況、タイムラインの配置情報をJSON化してBase64エンコードし、URLのハッシュ（#以降）に付与したリンクをクリップボードにコピーします。このURLを開くことで、状態を完全に復元できます。

## 4. タンタンの独自SP返還仕様の実装
- タンタンが「戦技」を使用する直前に「連携技」を発動した回数（最大2回）をシミュレーション内で追跡するロジックを追加しました。
- 無凸時は連携技1回につき20SP（最大40SP）、1凸設定時は連携技1回につき25SP（最大50SP）を、戦技発動時に返還SPプールに動的に加算します（加算後、カウントはリセットされます）。

## 5. 最低必要初期EPの逆算表示
- シミュレーション内で、各キャラクターが「自身の最初の必殺技を発動するまでに獲得した累計EP」を計測するようにしました。
- 必殺技の消費EPからこの獲得EPを差し引いた値を計算し、不足分を「最低必要初期EP」としてリザルトのステータス欄に表示する機能を追加しました。

## 6. キャラクターデータの修正
- `data/characters.json` 内のギルベルタの必殺技コスト軽減効果を、2凸から正しい4凸（`level: 4`）の設定へ修正しました。
