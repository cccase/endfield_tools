# アークナイツ：エンドフィールド ローテーション＆SPシミュレーター (V2 + Update)

## 概要
「アークナイツ：エンドフィールド」の戦闘スキル回し（ローテーション）と必殺技ゲージ蓄積（SP計算/EP計算）を可視化・シミュレーションするWebツールの要件定義です。純粋なHTML/CSS/Vanilla JavaScriptで構築し、ビルドツールなしでGitHub Pagesで動作することを前提としています。

実装は日本語。返答やコード内のコメントなども日本語。

## 基本機能要件（V1から継続）
- キャラクター・スキル選択パネルとタイムライン表示エリアの実装。
- ダークモード風のUI（黒・ダークグレー・黄/オレンジのアクセント）。
- レスポンシブ対応、タイムラインの横スクロール。
- JSONデータからの動的なキャラクター情報の読み込み。
- ドラッグ＆ドロップによるスキル配置。

## V2 追加要件
1. **パーティ編成とステータス調整**
   - タイムラインへのスキル配置前に、最大4人までのパーティを編成。
   - キャラクターごとに「チャージ効率（%）」と「凸数（潜在能力）」を設定可能にする。
2. **シーケンス（発動順）ベースのタイムライン**
   - 時間軸（秒）による管理ではなく、発動した順番（ステップ）によるシーケンスベースのタイムラインに変更。
3. **EP（必殺技ゲージ）の個別管理**
   - グローバルな「共有SP」の追跡ではなく、キャラクター個別の「EP（必殺技ゲージ）」を管理する。
   - 戦技（Skill）発動時、パーティ全員に「基準値（6.5）× (1 + 個別のチャージ効率)」のEPを付与する。
   - 連携技（Combo）発動時、発動した本人のみに「基準値（10）× (1 + 本人のチャージ効率)」のEPを付与する。
   - 必殺技（Ult）発動時、設定されたEPコストを消費する。不足している場合は警告を表示しつつシミュレーションを継続する。
4. **SP返還とEP獲得ペナルティ（SP Refund Mechanic）**
   - 特定のキャラクター（オクギ、タンタンなど）が持つ「返還SP」要素をタイムラインに配置可能にする。
   - 配置された返還SPは「返還SPプール」に蓄積される。
   - プールに返還SPがある状態で戦技（Skill）を使用すると、そのコスト（通常100）のうちプールから優先して消費される。
   - 返還SPが消費された割合に応じて、その戦技によるEP獲得量が減少する（例：30返還された場合、(100-30)/100 = 70%のEP獲得量となる）。
   - 凸（潜在能力）による返還SP量増加や、必殺技コスト減少効果をシミュレーションに反映する。
   - タイムライン上の返還SPブロックは、ユーザーが任意の数値を入力・調整できるようにする。

## アップデート（今回の追加修正）
1. **初期チャージ効率のデフォルト設定**
   - キャラクターごとに初期のチャージ効率（%）を以下の通り設定する：
     - タンタン：107
     - ギルベルタ：202.9
     - オクギ：153.4
     - ザイヒ：133.7
2. **凸情報とSP返還情報の更新**
   - `data/`フォルダ内の情報（Wiki HTML）から、各キャラクターの潜在能力（必殺チャージ減、返還SP等）や基礎返還SP情報を抽出し、`characters.json`を更新して反映させる。

3. **キャラクターデータの確認**
   - キャラクターデータ（`characters.json`）を読み込む際、そのキャラクターが「基礎返還SPを持っているか」「どの凸数で必殺技コストや返還SPが変化・追加されるか」を必ず確認し、正確に反映させること。
