# Endfield Rotation & SP Simulator 要件定義書

## 概要
アークナイツ：エンドフィールドの「戦闘スキル回し（ローテーション）」と「必殺技ゲージ蓄積（SP計算）」を可視化・シミュレーションするWebツール。
ビルドツールは使用せず、純粋な HTML / CSS / Vanilla JavaScript で構築する（GitHub Pagesでの静的ホスティングを想定）。

## 戦闘システムの理解（重要）
エンドフィールドの戦闘システムは以下の特徴を持ちます。
1. **SP（戦技ポイント）の共有**: 戦技（スキル）を使用するためのSPは**パーティー全体で共有**される。SPは時間経過や特定のアクション（重攻撃、ジャスト回避など）で回復する。通常は時間経過で回復（例：1秒間に約8回復）。
2. **スキルの種類**:
   - **戦技**: SPを消費して発動。クールタイムは無い（SPが許す限り連発可能）。
   - **連携技**: 特定条件で発動。クールタイムあり。
   - **必殺技**: 必殺チャージ（EP）を消費して発動。
3. **必殺チャージ（EP）の蓄積**:
   - 必殺技を使うためのチャージ（EP）は各キャラクター個別に蓄積される。
   - **戦技**を使うと、**パーティー全員の**必殺チャージが一律で 6.5 増加する。
   - **連携技**を使うと、**発動したキャラクターのみ**必殺チャージが 10 増加する。

## UI要件
- **ダークモードUI**: 黒・ダークグレーを基調とし、アクセントカラーにオレンジ/黄色を使用。
- **レスポンシブ対応**: タイムライン部分は横スクロール可能。
- 各キャラクターのスキル要素にはアイコン画像を表示（`image/` ディレクトリから読み込み）。UIの言語は**日本語**とする。

## 機能要件
1. **キャラクター・スキル選択パネル**
   - `data/characters.json` からデータを非同期で取得。
   - 取得データに基づき、キャラクターごとのカードをレンダリング（アイコン画像＋名前）。
   - 各カード内に、そのキャラクターが持つスキル（戦技・必殺技等）をドラッグ可能なブロックとして表示。
2. **タイムライン（横軸：時間）**
   - 0秒〜60秒のタイムライングリッドを表示。
   - ドラッグ＆ドロップでスキルブロックをタイムライン上に配置。
   - スキルブロック配置時、重複しないように縦位置を自動調整する。
   - 配置されたスキルは、そのスキルの効果・硬直時間（またはクールタイム）を表すブロックを付随して表示。
3. **SP / 必殺チャージ トラッカー**
   - 【要調整】当初は「獲得SPを加算」としていたが、エンドフィールドの仕様では**戦技はSPを消費**し、必殺チャージ（EP）を獲得する。
   - 本シミュレーターでは以下の2つのリソースをグラフ化/数値化する。
     1. **パーティー共有SP**: 毎秒自然回復（例: 8/s）、戦技使用で減少。
     2. **必殺チャージ（EP）**: 戦技使用で全員+6.5、必殺技使用で消費。
4. **シミュレーション再生**
   - 再生ボタンでタイムラインのカーソルが進行。
   - 時間経過に合わせて共有SPの増減、各キャラのEP蓄積をリアルタイムに計算し表示する。

この要件定義を基に、HTML, CSS, JSを実装してください。
