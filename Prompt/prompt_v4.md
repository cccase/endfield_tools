# V4 Request Prompt

1. タイムラインのエクスポート機能
2. タイムラインに、待ち時間用の仕切り（文字はいらない）
3. 必要最低の必殺チャージを逆計算できる機能
4. タンタンの返還SPは、戦技を打つ前に連携技を発動させた回数（最大2回まで）で変動
  + 連携技一回だと20SP返還（1凸で25SP）
  + 2回だと40SP（50SP）返還になる
5. ギルベルタの凸が違うかも？
  + 多分4凸効果
6. タイムラインを1本じゃなくて分けれるようにしたい
  + セットを複製みたいに
  + 下に増やせるように
    + 1サイクルをわかりやすくできるようにしたい（1サイクルみたいな文言はいらない。ただ、枠を分けたい）
7. エクスポート機能は2種類
  + 1つ目は、画像でエクスポート
  + 2つ目は、今回入力した状態を保持したURLを生成
    + そのURLを押したら、現在のタイムライン、効率、凸などが保持されている
